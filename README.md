# Уеб технологии

Материали за курса по уеб технологии — специалност **Софтуерно инженерство**, ФМИ, СУ „Св. Климент Охридски“.

Курсът минава през целия път на една уеб страница: от структурата в HTML, през оформлението в CSS и интерактивността с JavaScript, до сървърна логика в PHP, съхранение в база данни и накрая свързване на всичко в работещо приложение.

## Как работим на упражнение

Най-добре се учи с писане на ръка, а не с четене и копиране. Затова на упражненията:

1. **Раздели екрана на две** — в единия прозорец отвори урока, в другия упражненията към него.
2. **Отвори редактор** (VS Code или друг) и започни да пишеш задачите.
3. **Пиши кода сам, не копирай.** Грешките, които правиш докато пишеш, са най-полезната част.
4. **Питай веднага**, щом нещо не се получава — за това сме на упражнение.
5. **Накрая минаваме през всички задачи** заедно и ги разглеждаме.

Линковете в таблицата по-долу водят директно до всеки урок и упражнение, за да не се налага да пишеш пътища на ръка.

## Настройка

Клонирай хранилището:

```bash
git clone https://github.com/dTsvetkov13/web-technologies-course.git
```

**Модули 01–03 (HTML, CSS, JavaScript)** — достатъчен е текстов редактор и браузър. Отваряш `.html` файловете директно в браузъра.

**Модули 04–06 (PHP, бази данни, уеб приложение)** — нужен е локален сървър. Инсталирай [XAMPP](https://www.apachefriends.org/), клонирай хранилището в папката `htdocs` и пусни Apache и MySQL. Тогава примерите се отварят на адрес:

```
http://localhost/web-technologies-course/
```

## Номериране на задачите

Всяка задача има номер във формат `модул.тема.задача`:

```
02.03.04
│  │  └── задача 04
│  └───── Тема 03
└──────── Модул 02
```

Така номерът сам показва къде се намира задачата. Задачите с `00` на мястото на темата (например `06.00.01`) са проекти за целия модул, а не за една тема.
