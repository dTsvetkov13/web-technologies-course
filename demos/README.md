## Започни оттук: artist-mini-project

Малък сайт за текстове на песни — начална страница и по една страница за четирима изпълнители. Само HTML, без CSS и без JavaScript, точно както ще изглеждат твоите първи упражнения.

Няма нужда от сървър. Два начина да го пуснеш:

**Най-лесно — копирай един файл**

1. Отвори [`artist-mini-project/only-html/index.html`](artist-mini-project/only-html) в GitHub
2. Натисни иконата за копиране горе вдясно в кода
3. Постави го в свой файл `index.html` и го отвори с двоен клик

Линковете към страниците на изпълнителите още няма да работят, защото тези файлове ги нямаш. Самата начална страница се вижда напълно.

**За целия сайт — изтегли файловете**

1. Отвори началната страница на хранилището в GitHub
2. Зелен бутон **Code** → **Download ZIP**
3. Разархивирай и отвори `demos/artist-mini-project/only-html/index.html`

Сега работят и линковете между страниците.

> Папката се казва `only-html`, защото това е първата стъпка. През семестъра същият сайт ще се надгражда — с CSS за оформление, с JavaScript за интерактивност и накрая с PHP и база данни.

## Останалите демота — нужен е XAMPP

`forms-demos`, `php-includes` и `security-demo` съдържат PHP файлове. PHP се изпълнява на сървър, затова **двойният клик не работи** — браузърът ще ти покаже самия код вместо страницата, или ще предложи да свали файла. Това не е грешка, просто още няма кой да изпълни кода.

Когато стигнем до Модул 04, ще инсталираме XAMPP и тогава:

1. Изтегли файловете (Download ZIP или `git clone`)
2. Сложи папката в `htdocs` на XAMPP
3. Пусни Apache от XAMPP Control Panel (за `security-demo` — и MySQL)
4. Отвори `http://localhost/web-technologies-course/demos/<име-на-демото>/`

За `security-demo` трябва и база данни — SQL заявките са в [`security-demo/database/database.sql`](security-demo/database/database.sql), пускат се през `localhost/phpmyadmin`.

### Какво показва всяко

| Демо | Какво показва |
|---|---|
| [forms-demos](forms-demos) | HTML формуляри и обработката им в PHP. Всяко демо е в два варианта — без CSS и с CSS, за да се види какво променя оформлението. |
| [php-includes](php-includes) | Преизползване на header и footer с `include`, вместо да копираш един и същ код във всеки файл. |
| [security-demo](security-demo) | Регистрация и вход с PDO, `password_hash()` и prepared statements. |

> ⚠️ В `forms-demos/01-login-form` паролата се записва в текстов файл **нарочно**, за да се види какво точно изпраща формата към сървъра. Така не се прави в истински проект — правилният начин е в `security-demo`.
