# Практики - Модул 01: HTML

Практиката е задачата, по която работим в час. Една практика е за една част от занятието (около 45 минути): не е огромна, но не е и едно упражнение от два реда. Ако не я довършиш в час, довършваш вкъщи.

## Проектът: Музей на провалените изобретения

Google Glass. Segway. Nintendo Virtual Boy. New Coke. Всяко от тях някога е било „бъдещето“. Днес са експонати.

През целия семестър ще строиш сайта на един необикновен музей - **Музея на провалените изобретения**. Няма да правиш отделни малки страници, които после изтриваш. Ще имаш **един проект, който расте** с всеки модул:

| Модул | Какво добавяме към музея |
|---|---|
| **01 - HTML** | **Сградата:** страници, зали, експонати, формуляр за резервация |
| 02 - CSS | Интериорът: цветове, оформление, версия за телефон |
| 03 - JavaScript | Интерактивност: галерия, търсене и филтриране на експонати |
| 04 - PHP | Касата: резервациите се обработват на сървъра |
| 05 - Бази данни | Архивът: експонатите се пазят в база данни |
| 06 - Уеб приложение | Откриването: вход за уредниците и добавяне на нови експонати |

Защо точно провали? Защото в програмирането грешките са най-добрият учител. Музеят е посветен на тях - и твоите грешки по време на работа са част от експозицията.

## Как работим

1. **Отвори практиката** в едната половина на екрана, а редактора - в другата. Браузърът с твоята страница е до тях.
2. **Стъпките казват *какво* да постигнеш, а не *какъв* код да напишеш.** Кодът го измисляш ти, с помощта на уроците.
3. **Блокирал си?** Под всяка стъпка има **Подсказка**. Първо опитай сам 2-3 минути, после я прочети.
4. **Проверка** - накрая на всяка практика има списък. Мини през него, преди да кажеш „готов съм“.
5. **Ако ти остане време** - по-интересни неща за проучване, без подсказки. Не са задължителни.
6. **Въпроси за размисъл** - с тях завършваме часа заедно.

Всяка практика е за около 40 минути. Стъпките с **(вкъщи)** в заглавието не са за часа - правиш ги след това. Съдържание за експонатите (текст, снимки, дати) е готово в [експонати.md](файлове/експонати.md), за да не губиш време в търсене.

> **Не си довършил в час?** Довършваш вкъщи - практиките са написани така, че да можеш сам.

## Папката на проекта

Направи **една** папка `museum/` и я ползвай през целия семестър. Не правиш нова папка за всяка практика - музеят просто расте.

В края на Модул 01 папката ще изглежда така:

```
museum/
├── index.html          ← началната страница          (01.00.01)
├── exhibits.html       ← каталог на експонатите       (01.00.02)
├── visit.html          ← посещение и резервация       (01.00.02, 01.00.03)
├── media.html          ← мултимедийна зала            (01.00.04)
└── images/             ← всички снимки
    └── logo.svg
```

Едно правило за имената на файлове и папки: **латиница, малки букви, без интервали** (`about-us.html`, а не `За нас.html`). Сега няма значение, но когато сайтът отиде на сървър в Модул 04, ще има.

## Къде да търсиш

- **Уроците от модула** - всяка практика казва кои точно да държиш отворени.
- **[MDN - справочник за HTML елементи](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements)** - за всеки таг: какво прави, какви атрибути има, примери. Това ползват и професионалистите.
- **[W3C Validator](https://validator.w3.org/#validate_by_input)** - поставяш кода си и той ти казва къде има грешки.
- **[Wikimedia Commons](https://commons.wikimedia.org/)** и **Уикипедия** - снимки и информация за експонатите. Снимките там са със свободен лиценз.

## Чести съобщения от валидатора

Валидаторът пише на английски и не винаги ясно. **Error** е грешка, която трябва да оправиш; **Warning** и **Info** са съвети.

| Съобщението започва с… | Какво значи | Как се оправя |
|------------------------|-------------|---------------|
| An “img” element must have an “alt” attribute | снимка без `alt` | добави `alt`, който описва какво има на снимката |
| No “p” element in scope but a “p” end tag seen | в `<p>` има нещо, което не може да е в параграф - списък, заглавие, друг `<p>` | извади списъка или заглавието извън `<p>…</p>` |
| Element “ul” not allowed as child of element “ol” | вложеният списък е **между** `<li>`, а не вътре в тях | премести го вътре в `<li>`, преди `</li>` |
| Element “figcaption” not allowed as child of… | `<figcaption>` е извън `<figure>` | сложи го вътре във `<figure>` |
| Bad value “…” for attribute “id” | `id` с интервал | замени интервала с тире: `sinclair-c5` |
| Bad value “…” for attribute “datetime” | датата не е във формат за машини | `ГГГГ-ММ-ДД`, например `1985-01-10`, или само година |
| Bad value “350px” for attribute “width” | `width` е само число, без `px` | `width="350"` |
| Bad value “tel:…” for attribute “href”… Space is not allowed | телефон с интервали в `tel:` | без интервали: `tel:+359888123456` (на екрана може с интервали) |
| “…” element is a completely-unknown element / A slash was not immediately followed by “>” | в текста има `<` и браузърът го чете като таг - напр. написан направо `<blink>` или `<https://…>` от копиран текст | за знака пиши `&lt;`; при текст от Commons сложи отметка на **HTML** |
| Stray end tag “…” | затварящ таг, който няма отварящ | провери двойките тагове - вероятно има излишен `</…>` |
| End tag “…” seen, but there were open elements / Unclosed element “…” | забравен затварящ таг | намери къде трябва да е `</…>` |
| Section lacks heading *(warning)* | `<section>` без заглавие | добави `<h2>`… или ползвай `<div>`, ако не е смислова секция |
| The “border” attribute on the “table” element is obsolete *(warning)* | остарял атрибут (съобщението странно споменава `img` - не му обръщай внимание) | засега е наред - в Модул 02 рамките ще са с CSS |

> **Съвет:** Оправяй грешките **отгоре надолу** и проверявай отново след всяка. Една грешка горе често предизвиква още няколко под нея.
