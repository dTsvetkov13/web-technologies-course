# Първи стъпки — как да направиш и отвориш HTML файл

Прочети това преди първия урок. Отнема около 10 минути и след това вече можеш да работиш по упражненията.

Не ти трябва нищо инсталирано освен браузър и текстов редактор. Без Git, без сървър, без XAMPP — тях ще ги добавим по-късно в курса.

## 1. Направи папка за курса

Направи някъде папка, например `C:\web-course`. В нея ще слагаш всичко, което пишеш през семестъра. Добра идея е да имаш подпапка за всяко упражнение:

```
web-course/
├── 01.01.01/
├── 01.01.02/
└── ...
```

## 2. Включи разширенията на файловете (Windows)

**Направи това преди да създадеш първия файл.** По подразбиране Windows скрива разширенията (`.html`, `.txt`) и това създава най-честия проблем в началото: мислиш, че си направил `index.html`, а всъщност файлът е `index.html.txt` и браузърът не го отваря като страница.

В File Explorer:

- **Windows 11:** View → Show → File name extensions
- **Windows 10:** View → сложи отметка на „File name extensions“

Сега виждаш истинските имена на файловете.

## 3. Направи файла `index.html`

Най-лесно с редактор:

1. Инсталирай [VS Code](https://code.visualstudio.com/) (безплатен)
2. File → Open Folder → избери папката си
3. New File → име `index.html`

Работи и с Notepad, но VS Code оцветява кода и подсказва грешките, което помага много в началото.

> Файлът трябва да се казва `index.html`, а не `index.html.txt`. Ако си пропуснал стъпка 2, сега е момента.

## 4. Копирай този код във файла

За първия файл просто копирай — целта е да видиш нещо на екрана. От упражненията нататък ще пишеш кода сам, защото така се учи.

```html
<!DOCTYPE html>
<html lang="bg">
<head>
    <meta charset="UTF-8">
    <title>Моята първа страница</title>
</head>
<body>
    <h1>Здравей!</h1>
    <p>Това е първата ми уеб страница.</p>
</body>
</html>
```

Запази файла — `Ctrl + S`.

## 5. Отвори файла в браузъра

Два начина:

- **Двоен клик** върху `index.html` в File Explorer
- **Десен клик** → Open with → Chrome / Firefox

В адресната лента ще видиш нещо като `file:///C:/web-course/index.html`. Това е нормално — файлът се отваря директно от диска, без сървър.

## 6. Промени нещо и презареди

1. Смени текста в `<h1>` на нещо друго
2. Запази (`Ctrl + S`)
3. Върни се в браузъра и презареди с `F5` (или `Ctrl + R`)

Това е целият работен цикъл през първите три модула: **пиши → запази → презареди**. Ако промяната не се вижда, почти винаги файлът не е запазен.

## 7. Конзолата на браузъра

Натисни `F12` — това отваря DevTools. Засега ти трябва само табът **Console**: там браузърът показва грешките в страницата. От Модул 03 (JavaScript) ще я ползваш постоянно.

## Чести проблеми

| Проблем | Причина и решение |
|---|---|
| Файлът се отваря в Notepad вместо в браузъра | Името е `index.html.txt`. Включи разширенията (стъпка 2) и преименувай файла. |
| Браузърът показва самия код, а не страницата | Същата причина — грешно разширение. |
| Кирилицата излиза като `���` или въпросителни | Липсва `<meta charset="UTF-8">` в `<head>`, или файлът не е запазен като UTF-8. Във VS Code кодировката се вижда долу вдясно. |
| Промените не се виждат в браузъра | Файлът не е запазен, или страницата не е презаредена (`F5`). |
| Двойният клик отваря друга програма | Десен клик → Open with → избери браузър. |
