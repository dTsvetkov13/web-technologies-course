# Практики - Модул 02: CSS

🇬🇧 [English version](README.en.md)

Практиката е задачата, по която работим в час. Тук не пишеш страница от нулата - получаваш **готов сайт** и го подобряваш стъпка по стъпка, както се работи в истинска фирма.

## Проектът: Little Fern Coffee Co.

Little Fern е малко кафене с пържилня. Сайтът му вече съществува: има съдържание, цветове и шрифтове, но оформлението е недовършено. Логото стои над менюто, артикулите са в една дълга колона, нищо не реагира на мишката, а на телефон всичко е смачкано.

Твоята работа е да го довършиш с **5 задачи**. Всяка упражнява различна част от CSS:

| Задача | Какво правиш | CSS понятия | По темите |
|--------|--------------|-------------|-----------|
| 1 - Навигация | логото и линковете на един ред | `display: flex`, `justify-content`, `gap` | Тема 03 |
| 2 - Меню в решетка | картичките в 3 колони, цените подравнени долу | `display: grid`, `fr`, `gap` | Тема 04 |
| 3 - Ефекти при посочване | бутоните и картичките реагират на мишката | `:hover`, `transition`, `transform` | Тема 01, Тема 04 |
| 4 - Позициониране | етикет „Най-продавано“ и залепващ хедър | `position: relative / absolute / sticky` | Тема 02 |
| 5 - Адаптивност | 1 / 2 / 3 колони според екрана | `@media`, `clamp()`, mobile first | Тема 04 |

Задачите са **по ред** - всяка стъпва на предишната.

## Как работим

1. **Отвори сайта** `coffee-shop/bg/index.html` в браузъра, а `style.css` - в редактора.
2. **Отвори задачите** в един от трите формата (съдържанието е едно и също):
   - [задачи.md](coffee-shop/bg/задачи.md) - пълното описание, с подсказки
   - `coffee-shop/bg/challenges/index.html` - кратък преглед на един екран
   - `coffee-shop/bg/tickets/index.html` - същите задачи като спринт с 5 задачи (тикета), както ги получаваш на работа
3. **Променяй съществуващите файлове.** Не започвай отначало - подобряваш това, което вече има.
4. **След всяка задача отвори DevTools (F12)** и разгледай елементите: кои правила се прилагат, кои са задраскани и защо.
5. **Блокирал си?** Сравни с `coffee-shop/bg/solution/`. Всяка промяна там е отбелязана с коментар `ЗАДАЧА n`. Първо опитай сам.

> **Работиш с Claude или друг AI асистент?** Давай му по една задача и го молѝ да промени съществуващия код, а не да пише нов сайт. После прочети какво е променил и защо.

## Папката на проекта

```
coffee-shop/
├── bg/                    ← български
│   ├── index.html         ← началният сайт (тук работиш)
│   ├── style.css
│   ├── задачи.md          ← пълното описание на задачите
│   ├── challenges/        ← задачите на един екран
│   ├── tickets/           ← задачите като спринт
│   └── solution/          ← решение на петте задачи
└── en/                    ← същото на английски
    ├── index.html
    ├── style.css
    ├── CHALLENGES.md
    ├── challenges/
    ├── tickets/
    └── solution/
```

Двете версии имат **един и същ CSS** - различават се само текстовете и коментарите. Всяка страница има линк към другия език (`EN` / `BG`).

Сайтът е само HTML и CSS - отваря се с двоен клик, без сървър.
